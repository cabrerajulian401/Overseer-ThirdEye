# Azure AD Auth (AUTH_MODE=aad) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace MVP accept-any-bearer auth with real Azure AD validation + on-behalf-of (OBO) Graph token exchange, behind an `AUTH_MODE` env switch that defaults to the current MVP behavior.

**Architecture:** A new `internal/gateway/aad` package holds three dumb adapters (JWKS-backed JWT validator, OBO token-endpoint client, per-user token manager) plus a glue `Authenticator`. The HTTP layer gains one seam — an `Authenticator` interface the middleware consumes — with the current resolver/sink pair wrapped as the MVP implementation. `main.go` picks the implementation from `AUTH_MODE` and hands the aad token manager to the three background-job `TokenSource` ports in place of `tokencache.Cache`.

**Tech Stack:** Go 1.26, Echo v4, `github.com/golang-jwt/jwt/v5` (the one new dependency), stdlib crypto for JWKS→`rsa.PublicKey`.

## Global Constraints

- `AUTH_MODE` env var: `"mvp"` (default — exact current behavior) or `"aad"`. Anything else: log + exit(1) at startup.
- Env vars (already provisioned in ACA): `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_CLIENT_SECRET`. In aad mode all three are required at startup — fail fast.
- JWKS URL: `https://login.microsoftonline.com/common/discovery/v2.0/keys`, keys cached; refetch only on unknown `kid`, rate-limited to once/minute.
- Token validation: RS256 signature; audience == `AZURE_CLIENT_ID` **or** `api://<any-domain>/<client-id>`; issuer == `https://login.microsoftonline.com/{tid}/v2.0` with `tid` == `AZURE_TENANT_ID`; expiry (30s leeway); `scp` contains `access_as_user`.
- OBO: `POST https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token`, `grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer`, `requested_token_use=on_behalf_of`, `scope="https://graph.microsoft.com/.default offline_access"`. Exchange on first authenticated request per user; cache access+refresh token keyed by `oid` claim; refresh proactively (5-min margin) so background jobs keep working.
- Error semantics: auth failure → **401 with empty body** (both modes — this is the documented BE_Docs contract; existing tests assert status only). AAD consent/interaction-required → **403 `{"error":"interaction_required"}`** (FE maps to "reconnect your mailbox"). Sentinel: `entity.ErrReauthRequired` (entity is the only ring both http and aad may import).
- The `/ws?token=` query-param path (already deployed) must keep working in both modes — same validation as the header path (it reuses the same middleware via `wsQueryTokenFallback`).
- Never log token values (`TestWSTokenNeverLogged` guards /ws; keep aad code token-silent too).
- Existing test files must pass **unmodified**. Existing usecase `TokenSource` ports (`GraphToken(uuid.UUID) (string, bool)`) must not change.
- Clean-architecture direction: controller → usecase → gateway/repo; entity imports stdlib+uuid only. Comments follow existing density/style (explain constraints, not mechanics).
- Work on branch `aad-auth` off `main`. Commit at the end of every task. Pushing uses the HTTPS+gh trick (SSH is unavailable): `git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push https://cabrerajulian401@github.com/cabrerajulian401/Overseer-ThirdEye.git aad-auth`.
- All Go commands run in `overseer/` (the module root).

func newJWKSServer(t *testing.T, keys map[string]*rsa.PublicKey) *jwksServer {
	t.Helper()

// Package aad is the Azure AD adapter for AUTH_MODE=aad: it validates the
// add-in's Office-SSO tokens against Microsoft's published signing keys and
// trades them for Graph tokens via the on-behalf-of flow. Like every gateway
// it holds no business decisions — the http middleware and main.go decide
// when to call it.
package aad

import (
	"context"
	"crypto/rsa"
	"encoding/base64"
	"encoding/json"
	"fmt"
	"io"
	"math/big"
	"net/http"
	"slices"
	"strings"
	"sync"
	"time"

	"github.com/golang-jwt/jwt/v5"
)

// DefaultJWKSURL is the common-tenant discovery document; every AAD v2 token
// verifies against it regardless of tenant — tenant binding is the iss/tid
// check, not the key set.
const DefaultJWKSURL = "https://login.microsoftonline.com/common/discovery/v2.0/keys"

// RequiredScope is the delegated scope Scout requests via Office SSO; a token
// without it was minted for some other purpose and must not reach our API.
const RequiredScope = "access_as_user"

// jwksMinRefetch keeps a flood of made-up kids from turning every bad request
// into a JWKS fetch.
const jwksMinRefetch = time.Minute

// Claims is the slice of the validated token the rest of the system needs.
type Claims struct {
	OID   string // stable per-user object id — the token-cache key
	TID   string
	Email string // preferred_username, informational only
}

// Validator checks Office-SSO access tokens for our app registration:
// signature via the cached JWKS, audience, v2 issuer, expiry, and scope.
type Validator struct {
	ClientID   string
	TenantID   string
	JWKSURL    string       // defaults to DefaultJWKSURL
	HTTPClient *http.Client // defaults to http.DefaultClient

	now func() time.Time // test seam for the refetch rate limit

	mu          sync.Mutex
	keys        map[string]*rsa.PublicKey
	lastFetched time.Time
}

func (v *Validator) Validate(ctx context.Context, raw string) (Claims, error) {
	parser := jwt.NewParser(
		jwt.WithValidMethods([]string{"RS256"}),
		jwt.WithExpirationRequired(),
		jwt.WithLeeway(30*time.Second),
	)
	claims := jwt.MapClaims{}
	if _, err := parser.ParseWithClaims(raw, claims, func(t *jwt.Token) (any, error) {
		kid, _ := t.Header["kid"].(string)
		if kid == "" {
			return nil, fmt.Errorf("token has no kid header")
		}
		return v.keyFor(ctx, kid)
	}); err != nil {
		return Claims{}, fmt.Errorf("parse token: %w", err)
	}

	aud, err := claims.GetAudience()
	if err != nil || !v.audienceOK(aud) {
		return Claims{}, fmt.Errorf("token audience %v is not this app", aud)
	}
	tid, _ := claims["tid"].(string)
	if tid != v.TenantID {
		return Claims{}, fmt.Errorf("token tenant %q is not ours", tid)
	}
	if iss, _ := claims.GetIssuer(); iss != "https://login.microsoftonline.com/"+tid+"/v2.0" {
		return Claims{}, fmt.Errorf("issuer %q is not the v2 endpoint for tenant %q", iss, tid)
	}
	scp, _ := claims["scp"].(string)
	if !slices.Contains(strings.Fields(scp), RequiredScope) {
		return Claims{}, fmt.Errorf("token lacks the %s scope", RequiredScope)
	}
	oid, _ := claims["oid"].(string)
	if oid == "" {
		return Claims{}, fmt.Errorf("token has no oid claim")
	}
	email, _ := claims["preferred_username"].(string)
	return Claims{OID: oid, TID: tid, Email: email}, nil
}

// audienceOK accepts the bare client id and the api://<domain>/<client-id>
// Application ID URI — Office SSO mints either depending on manifest setup.
func (v *Validator) audienceOK(aud jwt.ClaimStrings) bool {
	for _, a := range aud {
		if a == v.ClientID {
			return true
		}
		if strings.HasPrefix(a, "api://") && strings.HasSuffix(a, "/"+v.ClientID) {
			return true
		}
	}
	return false
}

func (v *Validator) keyFor(ctx context.Context, kid string) (*rsa.PublicKey, error) {
	v.mu.Lock()
	defer v.mu.Unlock()
	if k, ok := v.keys[kid]; ok {
		return k, nil
	}
	now := time.Now
	if v.now != nil {
		now = v.now
	}
	if !v.lastFetched.IsZero() && now().Sub(v.lastFetched) < jwksMinRefetch {
		return nil, fmt.Errorf("unknown signing key %q", kid)
	}
	if err := v.fetchKeysLocked(ctx); err != nil {
		return nil, err
	}
	v.lastFetched = now()
	if k, ok := v.keys[kid]; ok {
		return k, nil
	}
	return nil, fmt.Errorf("unknown signing key %q", kid)
}

func (v *Validator) fetchKeysLocked(ctx context.Context) error {
	jwksURL := v.JWKSURL
	if jwksURL == "" {
		jwksURL = DefaultJWKSURL
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, jwksURL, nil)
	if err != nil {
		return fmt.Errorf("build jwks request: %w", err)
	}
	client := v.HTTPClient
	if client == nil {
		client = http.DefaultClient
	}
	res, err := client.Do(req)
	if err != nil {
		return fmt.Errorf("fetch jwks: %w", err)
	}
	defer res.Body.Close()
	if res.StatusCode != http.StatusOK {
		return fmt.Errorf("jwks endpoint returned %d", res.StatusCode)
	}
	var doc struct {
		Keys []struct {
			Kty string `json:"kty"`
			Kid string `json:"kid"`
			N   string `json:"n"`
			E   string `json:"e"`
		} `json:"keys"`
	}
	if err := json.NewDecoder(io.LimitReader(res.Body, 1<<20)).Decode(&doc); err != nil {
		return fmt.Errorf("decode jwks: %w", err)
	}
	keys := make(map[string]*rsa.PublicKey, len(doc.Keys))
	for _, k := range doc.Keys {
		if k.Kty != "RSA" || k.Kid == "" {
			continue
		}
		n, errN := base64.RawURLEncoding.DecodeString(k.N)
		e, errE := base64.RawURLEncoding.DecodeString(k.E)
		if errN != nil || errE != nil || len(n) == 0 || len(e) == 0 {
			continue
		}
		keys[k.Kid] = &rsa.PublicKey{N: new(big.Int).SetBytes(n), E: int(new(big.Int).SetBytes(e).Int64())}
	}
	v.keys = keys
	return nil
}

package aad

import (
	"context"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/url"
	"strings"
	"time"

	"github.com/thirdeye/overseer/internal/entity"
)

// GraphScope asks for a Graph token covering everything already consented to
// the app; offline_access makes the endpoint also return a refresh token.
const GraphScope = "https://graph.microsoft.com/.default offline_access"

// TokenSet is one grant response: the Graph access token, the refresh token
// that outlives it, and the absolute expiry computed from expires_in.
type TokenSet struct {
	AccessToken  string
	RefreshToken string
	ExpiresAt    time.Time
}

// OBOClient speaks to the tenant's v2.0 token endpoint: the on-behalf-of
// exchange for incoming user assertions, and the refresh grant that keeps
// background work alive between user sessions.
type OBOClient struct {
	TenantID     string
	ClientID     string
	ClientSecret string
	TokenURL     string       // defaults to the tenant's v2.0 token endpoint
	HTTPClient   *http.Client // defaults to http.DefaultClient
	Now          func() time.Time
}

func (c *OBOClient) Exchange(ctx context.Context, assertion string) (TokenSet, error) {
	return c.post(ctx, url.Values{
		"grant_type":          {"urn:ietf:params:oauth:grant-type:jwt-bearer"},
		"requested_token_use": {"on_behalf_of"},
		"client_id":           {c.ClientID},
		"client_secret":       {c.ClientSecret},
		"assertion":           {assertion},
		"scope":               {GraphScope},
	})
}

func (c *OBOClient) Refresh(ctx context.Context, refreshToken string) (TokenSet, error) {
	return c.post(ctx, url.Values{
		"grant_type":    {"refresh_token"},
		"client_id":     {c.ClientID},
		"client_secret": {c.ClientSecret},
		"refresh_token": {refreshToken},
		"scope":         {GraphScope},
	})
}

func (c *OBOClient) post(ctx context.Context, form url.Values) (TokenSet, error) {
	endpoint := c.TokenURL
	if endpoint == "" {
		endpoint = "https://login.microsoftonline.com/" + c.TenantID + "/oauth2/v2.0/token"
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, endpoint, strings.NewReader(form.Encode()))
	if err != nil {
		return TokenSet{}, fmt.Errorf("build token request: %w", err)
	}
	req.Header.Set("Content-Type", "application/x-www-form-urlencoded")
	client := c.HTTPClient
	if client == nil {
		client = http.DefaultClient
	}
	res, err := client.Do(req)
	if err != nil {
		return TokenSet{}, fmt.Errorf("token endpoint: %w", err)
	}
	defer res.Body.Close()
	body, err := io.ReadAll(io.LimitReader(res.Body, 1<<20))
	if err != nil {
		return TokenSet{}, fmt.Errorf("read token response: %w", err)
	}

	if res.StatusCode != http.StatusOK {
		var aadErr AADError
		if json.Unmarshal(body, &aadErr) != nil || aadErr.Code == "" {
			return TokenSet{}, fmt.Errorf("token endpoint returned %d", res.StatusCode)
		}
		return TokenSet{}, &aadErr
	}
	var grant struct {
		AccessToken  string `json:"access_token"`
		RefreshToken string `json:"refresh_token"`
		ExpiresIn    int    `json:"expires_in"`
	}
	if err := json.Unmarshal(body, &grant); err != nil || grant.AccessToken == "" {
		return TokenSet{}, fmt.Errorf("token endpoint returned unusable success body")
	}
	now := time.Now
	if c.Now != nil {
		now = c.Now
	}
	return TokenSet{
		AccessToken:  grant.AccessToken,
		RefreshToken: grant.RefreshToken,
		ExpiresAt:    now().Add(time.Duration(grant.ExpiresIn) * time.Second),
	}, nil
}

// AADError is a non-200 from the token endpoint. Description can carry PII-free
// AADSTS codes; token values never appear in it.
type AADError struct {
	Code        string `json:"error"`
	Suberror    string `json:"suberror"`
	Description string `json:"error_description"`
}

func (e *AADError) Error() string {
	return fmt.Sprintf("aad token endpoint: %s (suberror %q)", e.Code, e.Suberror)
}

// Is reports entity.ErrReauthRequired for the "user must come back" family so
// callers distinguish reconnect-your-mailbox from plain outages.
func (e *AADError) Is(target error) bool {
	return target == entity.ErrReauthRequired && e.needsInteraction()
}

// needsInteraction: AAD signals it three ways — error=interaction_required,
// invalid_grant suberrors, or AADSTS codes in the description (65001 consent,
// 50076/50079 MFA, 53003 conditional access, 50173/70008 expired or revoked
// grants).
func (e *AADError) needsInteraction() bool {
	if e.Code == "interaction_required" {
		return true
	}
	switch e.Suberror {
	case "consent_required", "basic_action", "message_only", "conditional_access":
		return true
	}
	for _, code := range []string{"AADSTS65001", "AADSTS50076", "AADSTS50079", "AADSTS53003", "AADSTS50173", "AADSTS70008"} {
		if strings.Contains(e.Description, code) {
			return true
		}
	}
	return false
}

package aad

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"sync"
	"time"

	"github.com/google/uuid"

	"github.com/thirdeye/overseer/internal/entity"
)

// refreshMargin treats tokens this close to expiry as expired, so a Graph
// call started "just in time" doesn't die mid-flight.
const refreshMargin = 5 * time.Minute

// backgroundTimeout bounds the network call GraphToken may make — its callers
// (scheduler ticks) carry no request context to inherit.
const backgroundTimeout = 15 * time.Second

type exchanger interface {
	Exchange(ctx context.Context, assertion string) (TokenSet, error)
	Refresh(ctx context.Context, refreshToken string) (TokenSet, error)
}

// Manager is aad mode's replacement for tokencache.Cache: one Graph
// access+refresh pair per user, keyed by the token's oid claim, filled by the
// OBO exchange on the HTTP path and renewed via the refresh grant for
// background jobs. In-memory like the cache it replaces — a restart needs one
// authed request to re-prime (documented gap, unchanged from MVP).
type Manager struct {
	obo exchanger
	log *slog.Logger

	// One mutex guards everything, held across the network calls too: MVP is
	// single-user, so serializing exchanges is simpler than singleflight and
	// also stops a stampede of ticks from double-refreshing.
	mu        sync.Mutex
	byOID     map[string]*entry
	oidByUser map[uuid.UUID]string
}

type entry struct {
	tokens TokenSet
	// needsReauth stops background refresh retries once AAD says only the
	// user can fix it; the user's next authed request clears it.
	needsReauth bool
}

func NewManager(obo exchanger, log *slog.Logger) *Manager {
	return &Manager{obo: obo, log: log, byOID: map[string]*entry{}, oidByUser: map[uuid.UUID]string{}}
}

// EnsureGraphToken returns a valid Graph token for the request's user,
// running the OBO exchange only when the cache can't serve one (first sight,
// near expiry, or a flagged reauth). The error may be entity.ErrReauthRequired.
func (m *Manager) EnsureGraphToken(ctx context.Context, userID uuid.UUID, oid, assertion string) (string, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	m.oidByUser[userID] = oid
	if e := m.byOID[oid]; e != nil && !e.needsReauth && time.Until(e.tokens.ExpiresAt) > refreshMargin {
		return e.tokens.AccessToken, nil
	}
	set, err := m.obo.Exchange(ctx, assertion)
	if err != nil {
		return "", fmt.Errorf("obo exchange: %w", err)
	}
	m.byOID[oid] = &entry{tokens: set}
	return set.AccessToken, nil
}

// GraphToken satisfies the usecase TokenSource ports (messages,
// subscriptions, checkups). Background callers hold no assertion to
// re-exchange, so near-expiry renews via the refresh token instead.
func (m *Manager) GraphToken(userID uuid.UUID) (string, bool) {
	m.mu.Lock()
	defer m.mu.Unlock()
	oid, ok := m.oidByUser[userID]
	if !ok {
		return "", false
	}
	e := m.byOID[oid]
	if e == nil || e.needsReauth {
		return "", false
	}
	if time.Until(e.tokens.ExpiresAt) > refreshMargin {
		return e.tokens.AccessToken, true
	}
	if e.tokens.RefreshToken == "" {
		return "", false
	}
	ctx, cancel := context.WithTimeout(context.Background(), backgroundTimeout)
	defer cancel()
	set, err := m.obo.Refresh(ctx, e.tokens.RefreshToken)
	if err != nil {
		if errors.Is(err, entity.ErrReauthRequired) {
			e.needsReauth = true
		}
		if m.log != nil {
			m.log.Error("graph token refresh failed", "error", err)
		}
		return "", false
	}
	if set.RefreshToken == "" {
		set.RefreshToken = e.tokens.RefreshToken
	}
	e.tokens = set
	return set.AccessToken, true
}

package aad

import (
	"context"
	"fmt"

	"github.com/google/uuid"

	"github.com/thirdeye/overseer/internal/entity"
)

type claimsValidator interface {
	Validate(ctx context.Context, raw string) (Claims, error)
}

type graphEnsurer interface {
	EnsureGraphToken(ctx context.Context, userID uuid.UUID, oid, assertion string) (string, error)
}

// Authenticator is aad mode's answer to the http layer's Authenticator seam:
// validate our app's token, OBO-exchange it for the Graph token, resolve the
// user. Still single-user — User is the seeded operator; multi-user later
// resolves from Claims here, nowhere else.
type Authenticator struct {
	Validator claimsValidator
	Tokens    graphEnsurer
	User      entity.User
}

func (a Authenticator) Authenticate(ctx context.Context, bearer string) (entity.User, string, error) {
	claims, err := a.Validator.Validate(ctx, bearer)
	if err != nil {
		return entity.User{}, "", fmt.Errorf("validate token: %w", err)
	}
	graphToken, err := a.Tokens.EnsureGraphToken(ctx, a.User.ID, claims.OID, bearer)
	if err != nil {
		return entity.User{}, "", err
	}
	return a.User, graphToken, nil
}

package http

import (
	"context"
	"errors"
	"net/http"
	"strings"

	"github.com/google/uuid"
	"github.com/labstack/echo/v4"

	"github.com/thirdeye/overseer/internal/entity"
)

// UserResolver turns a bearer token into the authenticated user. MVP
// single-user mode resolves every valid-looking token to the seeded user;
// multi-user later swaps this implementation, not the middleware.
type UserResolver interface {
	Resolve(ctx context.Context, token string) (entity.User, error)
}

// TokenSink receives the Graph token from every authed request so background
// jobs (webhook handling, subscription renewal) can call Graph later.
type TokenSink interface {
	Put(userID uuid.UUID, token string)
}

// Authenticator turns a bearer token into the authenticated user plus the
// Graph token downstream code should use. mvp mode passes the bearer straight
// through; aad mode validates it as our app's token and OBO-exchanges it.
type Authenticator interface {
	Authenticate(ctx context.Context, bearer string) (user entity.User, graphToken string, err error)
}

// AuthContext is what handlers read instead of the request body: userId and
// accountId always come from auth, never from the client.
type AuthContext struct {
	AccountID  string
	UserID     string
	User       entity.User
	GraphToken string
}

const authContextKey = "overseer.auth"

// mvpAuthenticator is the current shortcut expressed as an Authenticator: any
// resolvable bearer IS the Graph token, and the sink keeps it warm for
// background jobs.
type mvpAuthenticator struct {
	resolver UserResolver
	tokens   TokenSink
}

func (a mvpAuthenticator) Authenticate(ctx context.Context, bearer string) (entity.User, string, error) {
	user, err := a.resolver.Resolve(ctx, bearer)
	if err != nil {
		return entity.User{}, "", err
	}
	if a.tokens != nil {
		a.tokens.Put(user.ID, bearer)
	}
	return user, bearer, nil
}

// AuthMiddleware is the mvp-mode constructor, kept so existing wiring and
// tests build unchanged.
func AuthMiddleware(resolver UserResolver, tokens TokenSink) echo.MiddlewareFunc {
	return AuthMiddlewareWith(mvpAuthenticator{resolver: resolver, tokens: tokens})
}

// AuthMiddlewareWith requires `Authorization: Bearer <token>` and stashes the
// resolved AuthContext on the request. Failures are 401 with an empty body
// (the documented contract — nothing about why leaks to callers), except the
// one case the user must fix themselves: a Graph consent/interaction error,
// surfaced as 403 {"error":"interaction_required"} for the FE to map to
// "reconnect your mailbox".
func AuthMiddlewareWith(a Authenticator) echo.MiddlewareFunc {
	return func(next echo.HandlerFunc) echo.HandlerFunc {
		return func(c echo.Context) error {
			header := c.Request().Header.Get("Authorization")
			token, ok := strings.CutPrefix(header, "Bearer ")
			if !ok || strings.TrimSpace(token) == "" {
				return c.NoContent(http.StatusUnauthorized)
			}

			user, graphToken, err := a.Authenticate(c.Request().Context(), token)
			if err != nil {
				if errors.Is(err, entity.ErrReauthRequired) {
					return c.JSON(http.StatusForbidden, errorResponse{Error: "interaction_required"})
				}
				return c.NoContent(http.StatusUnauthorized)
			}

			c.Set(authContextKey, AuthContext{
				AccountID:  user.AccountID.String(),
				UserID:     user.ID.String(),
				User:       user,
				GraphToken: graphToken,
			})
			return next(c)
		}
	}
}

func authFrom(c echo.Context) AuthContext {
	auth, _ := c.Get(authContextKey).(AuthContext)
	return auth
}

		manager := aad.NewManager(&aad.OBOClient{
			TenantID:     cfg.AzureTenantID,
			ClientID:     cfg.AzureClientID,
			ClientSecret: cfg.AzureClientSecret,
		}, log)
		routerAuth = aad.Authenticator{
			Validator: &aad.Validator{ClientID: cfg.AzureClientID, TenantID: cfg.AzureTenantID},
			Tokens:    manager,
			User:      seedUser,
		}
		graphTokens = manager
		tokenSink = nil
		log.Info("auth mode: aad", "clientId", cfg.AzureClientID, "tenantId", cfg.AzureTenantID)
	default:
		log.Error("unknown AUTH_MODE", "mode", cfg.AuthMode)
		os.Exit(1)
	}
```

# 🔐 Overseer Auth — AUTH_MODE=aad (Azure AD + On-Behalf-Of)

> **What this is** — how Overseer authenticates Scout's requests once
> `AUTH_MODE=aad` is set: the add-in's Office-SSO token is validated for real
> (signature/audience/issuer/expiry/scope), then exchanged on-behalf-of the
> user for the Microsoft Graph token every feature uses. `AUTH_MODE=mvp`
> (the default) keeps the old accept-any-bearer behavior so deploys don't
> break before the FE flips.

## ⚡ The two modes

| | `mvp` (default) | `aad` |
|---|---|---|
| What the FE sends | any bearer (today: a raw Graph token) | the Office-SSO token for OUR app registration (scope `access_as_user`), via `OfficeRuntime.auth.getAccessToken` |
| What Overseer does with it | passes it straight to Graph | validates it, then OBO-exchanges it for a Graph token |
| Graph calls use | the incoming bearer | the exchanged Graph access token (cached + refreshed per user) |
| Background jobs | last bearer seen, in-memory | cached Graph token, auto-refreshed via the refresh token |

Both HTTP `Authorization: Bearer <token>` and the websocket `GET /ws?token=`
path go through the SAME validation — the query param is promoted into the
header before the shared middleware runs.

## ✅ What "validated" means (aad mode)

- RS256 signature against Microsoft's JWKS
  (`https://login.microsoftonline.com/common/discovery/v2.0/keys`, cached;
  refetched only on unknown `kid`, at most once/minute)
- `aud` = `AZURE_CLIENT_ID` (or `api://<domain>/<client-id>`)
- `iss` = `https://login.microsoftonline.com/{tid}/v2.0` and `tid` = `AZURE_TENANT_ID`
- `exp` (30s leeway) · `scp` contains `access_as_user` · `oid` present

## 🔄 The OBO exchange + token cache

First authenticated request per user → `POST /{tenant}/oauth2/v2.0/token`
with `grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer`,
`requested_token_use=on_behalf_of`, `scope="https://graph.microsoft.com/.default offline_access"`.
The returned Graph access + refresh tokens are cached per user (keyed by the
token's `oid` claim). Background work (checkup sends, subscription renewal,
webhook processing) reads this cache; within 5 minutes of expiry the refresh
token renews it automatically — no user session needed. The cache is
in-memory: after a restart, the first authed request re-primes it (same
liveness gap as mvp, unchanged).

## 🚨 Error semantics (what the FE must handle)

| Status | Body | Meaning | FE action |
|---|---|---|---|
| `401` | *empty* | missing/invalid/expired token | acquire a fresh SSO token, retry |
| `403` | `{"error":"interaction_required"}` | AAD refused the Graph exchange — consent revoked, MFA step-up, conditional access | show **"reconnect your mailbox"** → interactive re-consent |

Every authed route behaves this way, including the `/ws` handshake.

## ⚙️ Env vars

| Var | Purpose |
|---|---|
| `AUTH_MODE` | `mvp` (default) or `aad` |
| `AZURE_CLIENT_ID` | the shared FE/BE app registration (also the token audience) |
| `AZURE_TENANT_ID` | tenant bound into issuer validation and the token endpoint |
| `AZURE_CLIENT_SECRET` | client credential for the OBO exchange |

All three AZURE_* are required when `AUTH_MODE=aad` — the server refuses to
start without them.
```
